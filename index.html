🎮 Shader Lab の使い方

これは何？

ブラウザ上で Minecraft のシェーダーパックをプレビューできるツールです。時間と天候を自由に変えながら、3D 視点移動で見て回れます。

操作方法

  • 視点回転: マウスドラッグ（飛行モードはクリックでマウスロック）
  • 移動: WASD（飛行モード）/ Space=上 / Shift=下
  • ズーム: ホイール
  • パネル開閉: Tab キー
  • スクリーンショット: P キー
  • カメラモード切替: F キー
  • 時間プリセット: 1 夜明け / 2 昼 / 3 夕焼け / 4 夜

シェーダーパックの読み込み

OptiFine / Iris 形式（shaders/ フォルダ入り zip）を読み込めます。対応は簡易サブセットのため、複雑な大型パックは部分的に動作しないことがあります。失敗したプログラムは自動的に内蔵シェーダーへフォールバックします（「プログラム状態」で詳細を確認できます）。

GitHub Pages での公開

同梱の README.md に手順があります。zip を展開してリポジトリにコミットするだけで公開できます。
